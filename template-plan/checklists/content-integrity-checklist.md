# Content Integrity Checklist

- [ ] Required section keys exist for required routes.
- [ ] Required fields exist for required section keys.
- [ ] Renderer mapping exists for each required section key.
- [ ] Section order matches approved page composition.
- [ ] Required assets/icons/SVGs are present for required scope.
- [ ] Required interactive states are present for required scope.
- [ ] Unmapped sections are resolved or explicitly deferred.
- [ ] Reconciliation report confirms no missing required items.
