# shadcn / UI components

This starter follows the default **shadcn** layout: generated components live in `components/ui/` (see `components.json`).

From the `starter/` root (after `npm install`), add more primitives with the CLI, for example:

```bash
npx shadcn@latest add input dialog sheet accordion tabs form badge separator
```

Use `components/primitives/` for thin wrappers and `components/sections/` for page-level blocks that compose `ui/` + CMS data.
